# 🎓 Repositório Acadêmico

Este repositório é dedicado à organização, versionamento e armazenamento de todos os meus materiais, anotações e projetos universitários. 

Atualmente, concilio duas formações simultâneas e utilizo este espaço para centralizar meu progresso, documentar meu aprendizado e estruturar meu portfólio acadêmico:

*   **Ciência da Computação (CC)** – Universidade Federal de Mato Grosso (UFMT)
*   **Análise e Desenvolvimento de Sistemas (ADS)** – UniCathedral

## 📂 Estrutura de Pastas

Os arquivos foram migrados de plataformas em nuvem tradicionais para cá, visando aplicar o controle de versão na minha rotina de estudos. A estrutura principal está dividida da seguinte forma:

*   📁 `/faculdade-ufmt-cc`: Arquivos, slides, trabalhos práticos e códigos referentes às disciplinas do bacharelado.
*   📁 `/faculdade-unicathedral-ads`: Materiais, anotações, projetos e documentações do curso tecnólogo.

## 🚀 Objetivo

Além de servir como backup e organização pessoal, este repositório reflete minha evolução nos estudos. A ideia é manter todo o ciclo de desenvolvimento acadêmico versionado, permitindo que eu e outras pessoas possamos acompanhar o avanço das disciplinas, desde conceitos teóricos até a implementação de sistemas e projetos práticos.
